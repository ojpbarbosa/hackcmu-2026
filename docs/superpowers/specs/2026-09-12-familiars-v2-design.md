# Familiars v2 — build spec (sub-hour slice on top of the existing app)

Status: approved direction (mockups `docs/mockups/familiars.html`, deck `docs/deck/familiars.pptx`). Product name: **Familiars**. Palate and Detour are archived (routes removed from the launcher, code left in place). The launcher is no longer the entry; `/` redirects to `/familiars`.

## What we are shipping, in priority order

The cut line is hard. Everything above it must work on two iPhones over HTTPS before anything below it starts.

**P0 (the demo)**
1. **Dusk theme + creatures.** New tokens (`--bg #0F1133 → #2A1A55`, glass surfaces, gold/mint/rose accents, Bricolage display). One `<Creature>` component that renders any familiar from a seed (see generator below), with idle bob, blink, and aura.
2. **Hatch.** Screen 1: name + pronoun chips (he/him, she/her, they/them, own). Screen 2: talk. The phone records (MediaRecorder, 10–15 s chunks) → `POST /api/stt` (ElevenLabs Scribe) → tokens appear on the egg as the transcript grows → `hatch` action with the transcript → familiar. Three suggestion cards with example lines; each checks off when the transcript covers it (keyword match, client-side).
3. **Meet.** Casting mode arms the phone (presence in the room with `casting:true`). One wiggle (DeviceMotion spike) creates a pending cast visible to every other armed phone in the room for 8 s; those phones show the catch card; tapping **Catch** pairs them. No second wiggle, no timing window. Then the duet: the exchange lines stream one at a time as subtitles under the stage; the "you both" card; a TTS line per familiar when the ElevenLabs key is present.
4. **Web (home).** Your creature at the bottom, met people around it grouped by shared keyword (the strongest shared keyword becomes the label), friends of friends faint, "N you keep missing" entry, recap bubble.
5. **Out (scout + swipe).** "Send <name> out" with a brief (shared keywords, area, weekend, budget) → server runs the scout: Querit search → K2 375B picks leads → Querit page fetch → K2 extracts facts → up to three cards (`listed_event` with source + checked time, or `self_organized` labeled). Deck swipe (right = in, left = out). When every member of the circle swiped right on the same card → group match screen + ICS.

**P1 (if P0 is done and verified)**
6. Daily cast with listening: the cast lands (server time), the phone records and sends chunks to STT, K2 attributes answers to members from the transcript (best effort; the UI lets anyone re-assign with a tap).
7. Nightly recap (K2 375B from the day's graph) + the bubble.
8. Projector view (reuse the existing familiars stage with the new theme).

## Why hatching was slow, and the fix

The hatch called K2 375B with default `reasoning_effort` (high) and a large `max_tokens`, serially after the form. Fix: `reasoning_effort: 'low'`, `max_tokens: 300`, a tight JSON schema (`{name, keywords[5], clusterLabel, greeting}`), and start the call while the user is still talking (send the transcript so far after each STT chunk; the last one wins). Target: hatch visible within 2 s of "Done".

## Procedural creatures

Seed = hash(memberId). From the seed:
- **species** (4 bodies, all cute, no pixel art): moth (wings + antennae), kestrel (ears + crest + beak), gecko (tail + spots), pika (round ears). Add two more only if time allows: axolotl (gills), fox (pointed ears).
- **palette**: 8 aura hue pairs (gold, indigo, mint, rose, sky, lilac, coral, teal); body = hue, highlight = lighter, dark = darker.
- **eyes** (3): round, wide, sleepy (lid path). **mouth** (3): smile, small, open. **accessory** (4): none, freckles, glasses, tiny hat.
That is 4 × 8 × 3 × 3 × 4 = 1,152 distinct familiars from one SVG component with CSS variables and conditional paths.

**Names**: capitalized, from a curated list keyed by species and hue so they feel earned: Merlin, Raven, Sage, Nova, Wren, Juniper, Onyx, Ember, Atlas, Luna, Ferro, Indigo, Sable, Comet, Fennel, Basil, Pippin, Quill, Ozzy, Tamsin, Nimbus, Marlow, Sol, Vesper. The 375B may propose one from the transcript; the list is the fallback and the filter (no human names of people in the room).

## Tech stack (unchanged where possible)

- Next.js 15 on Vercel (existing), Upstash store (live), rooms via polling (existing), `act()` reducers (existing `familiars.ts` extended; `cast.ts` folded in as the `casts` slice).
- **IFM K2 Horizon 375B** via `llm.json` (existing) for hatch, exchange, casts, recap, scout planning and extraction. **K2 Horizon 0.9B** per familiar: served from the laptop via MLX (`mlx_lm.server`) behind `LLM_SMALL_BASE_URL`; the exchange lines are generated by the two familiars' small instances when the endpoint is up, and by 375B otherwise. The ladder shows which one answered. Never claim local when it is not running.
- **ElevenLabs**: `POST /api/stt` (Scribe, `scribe_v1`) for hatch and the listening cast; `POST /api/tts` (a voice per aura hue, 8 voices) for the duet and "Hear <name>". Env: `ELEVENLABS_API_KEY`.
- **Querit**: `search(q)` and `fetch(url)` behind `src/lib/scout/provider.ts`; `QUERIT_API_KEY`. Cached results for the demo in `src/lib/scout/cache/*.json`, labeled "cached" on the card when used.
- Wiggle: DeviceMotion (permission on tap), spike > 14 m/s², server `casts:<room>` pending list (TTL 8 s), catch = `act('catch', {castId})`.
- iPhone frame: on viewports wider than 500 px, the app renders inside a 393×852 device frame centered on the dusk board, so the desktop demo is still mobile.

## Routes (one app)

```
/familiars                 hatch (name → talk → hatched)  [redirect to /familiars/web when hatched]
/familiars/web             home
/familiars/meet            casting mode / catch / duet
/familiars/missed          the ones you keep missing + intro
/familiars/casts           tonight's cast · out (scout deck) · group match
/familiars/you             your familiar · recap
/familiars/stage           projector
```

Tabs: web · casts · you (the you tab icon is your creature).

## Server state additions (familiars room)

```
members[id].profile = { name, pronouns, transcript, keywords[], seed, creature:{species,hue,eyes,mouth,accessory}, voiceId }
casting: { [memberId]: { armedAt } }
pendingCasts: [{ id, from, at }]            # a wiggle; visible to armed members for 8 s
pairs: [{ id, a, b, lines[], youBoth, say, at }]
circles: [{ id, name, members[], nextCastAt }]
scout: { [circleId]: { brief, status[], cards[], swipes:{[cardId]:{[memberId]:'in'|'out'}}, match?: cardId } }
recaps: { [memberId]: { cards[], at } }
```

Actions: `profile`, `arm`, `disarm`, `wiggle`, `catch`, `talked`, `askIntro`, `scout`, `swipe`, `castNow`, `listen` (transcript chunk), `recap`.

## Model tasks (server, JSON)

- `familiars.hatch` (375B, low): `{name, pronouns, transcript}` → `{familiarName, keywords[5], clusterLabel, greeting}`.
- `familiars.exchange` (0.9B ×2 when available, else 375B): `{a, b}` → `{lines[4], youBoth, say}`.
- `familiars.intro` (375B): `{me, them, via}` → `{line}`.
- `scout.plan` (375B): `{brief}` → `{queries[3]}`; `scout.extract` (375B): `{page text}` → `{title, whenISO, where, cost, unknowns[], kind}`; `scout.fit` (375B): `{cards, circle}` → `{why per card}`.
- `casts.prompt` (375B): `{circle keywords}` → `{question ≤ 8 words, hook ≤ 8 words}`; `casts.attribute` (375B): `{transcript, members}` → `{answers:{memberId:text}}`.
- `familiars.recap` (375B): `{graph for me}` → `{cards[3]}`.

## Demo script (3 minutes, two phones + projector)

Hatch on phone A by voice (15 s) → arm both, wiggle A, catch on B → duet with voices → web on A shows B and the missing → "Send Merlin out" → three cards → both swipe right on one → group match → recap bubble.

## Acceptance

Two iPhones on production complete hatch → wiggle → catch → duet in under 60 s; the deck shows real Querit-sourced cards or clearly labeled cached ones; the ladder is honest about which model answered.
