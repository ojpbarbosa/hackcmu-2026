# Detour Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Detour on the shared core: set-out form, a real walking graph of Oakland, an orienteering solver, model-written nudges, a fogged MapLibre map with a demo-walk replay, the wall, the arrival reveal, and a stage view showing the hidden route and candidates.

**Architecture:** OSM data fetched once by a script into `web/src/lib/detour/oakland.json` (graph + POIs). Solver and nudge generation run in the reducer (`web/src/lib/apps/detour.ts`) so the stage sees the same walk. Client route group `web/app/detour/*`; map via `maplibre-gl` with the OpenFreeMap `liberty` style (no key), fog as a canvas overlay, position from `watchPosition` or the demo replay.

**Tech Stack:** as core. Extra: `maplibre-gl`, `@turf/distance` (or a 20-line haversine), `tsx` script for Overpass fetch.

**Spec:** `docs/superpowers/specs/2026-09-12-detour-design.md`. Visual contract: `docs/mockups/index.html` §Detour.

## Global Constraints

- Same as the core plan. Only touch `web/src/lib/apps/detour.ts`, `web/src/lib/detour/**`, `web/src/lib/tasks/detour.ts`, `web/src/lib/mock/detour.*.ts`, `web/app/detour/**`, `web/scripts/fetch-osm.ts`, `web/test/detour.*.test.ts`, and add deps to `web/package.json`.
- The destination is never rendered on the phone before arrival. The fog is real (canvas mask), not a blur.
- Geolocation and the map need HTTPS on iOS; local testing uses the demo replay.

### Task 1: OSM data and graph

**Files:** `scripts/fetch-osm.ts`, `src/lib/detour/graph.ts`, `src/lib/detour/oakland.json`, tests

**Interfaces (produces):**
```ts
// fetch-osm.ts: Overpass QL for bbox (40.437,-79.965,40.452,-79.935):
//   way["highway"~"footway|path|pedestrian|residential|living_street|service|tertiary|secondary|primary|steps|unclassified"](bbox); node(w); and nodes/ways with name and (amenity|shop|tourism|leisure|historic) as POIs.
//   Write oakland.json with dedup nodes, edges with haversine meters and the way's name, POIs snapped to nearest graph node. Skip if the file exists unless --force. Overpass endpoint https://overpass-api.de/api/interpreter (fallback https://overpass.kumi.systems/api/interpreter). Keep the file < 3 MB (drop edges outside bbox, round coords to 6 decimals).
export type Graph={nodes:Record<string,[number,number]>; adj:Record<string,{to:string; m:number; street:string}[]>; pois:Poi[]};
export type Poi={id:string; name:string; lat:number; lng:number; kind:string; tags:Record<string,string>; nodeId:string};
export function loadGraph():Graph;
export function nearestNode(g:Graph, lat:number, lng:number):string;
export function dijkstra(g:Graph, from:string):{dist:Record<string,number>; prev:Record<string,string>};
export function pathTo(prev:Record<string,string>, to:string):string[];
export function pathLatLng(g:Graph, nodeIds:string[]):[number,number][];
export function streetsAlong(g:Graph, nodeIds:string[]):string[]; // distinct street names in order
```
- [ ] **Step 1:** Run the fetch script once (commit the JSON). Tests: `nearestNode` of Tepper's coordinates returns a node within 60 m; `dijkstra` from Tepper to Cathedral gives a distance between 400 and 1200 m. Commit "feat(detour): oakland graph".

### Task 2: Solver

**Files:** `src/lib/detour/solver.ts`, `test/detour.solver.test.ts`

**Interfaces (produces):**
```ts
export type WalkLeg={fromNode:string; toNode:string; poi:Poi|null; path:[number,number][]; meters:number; seconds:number; streets:string[]; turn:'left'|'right'|'straight'};
export type Walk={legs:WalkLeg[]; totalSeconds:number; budgetSeconds:number; endpoint:{name:string; lat:number; lng:number}; candidates:{poi:Poi; novelty:number; considered:boolean}[]; novelty:number};
export function planWalk(g:Graph, start:[number,number], endpoint:{name:string;lat:number;lng:number}, budgetMin:number, mood:string, visitedPoiIds:string[]):Walk;
// Greedy insertion: speed 1.35 m/s; slack 180 s; novelty(poi) = 1 (never visited) × kindWeight(mood) × offAvenuePenalty (0.6 if on Forbes/Fifth) ; at each step pick the POI maximizing novelty / detourSeconds among those keeping (time so far + to POI + POI→endpoint) ≤ budget−slack; stop at 7 legs or when nothing fits; final leg to the endpoint. turn from the bearing change between consecutive legs.
```
- [ ] **Step 1:** Tests: budgets 15/45/90 from Tepper/Gates/Cathedral each return a feasible walk (`totalSeconds ≤ budget*60`), ≥ 1 leg, last leg ends within 60 m of the endpoint; 45-min walk has ≥ 3 POIs. Implement; pass. Commit "feat(detour): solver".

### Task 3: State, reducer, prompts, mocks

**Files:** `src/lib/apps/detour.ts`, `src/lib/tasks/detour.ts`, `src/lib/mock/detour.*.ts`

**Interfaces (produces):**
```ts
export type DetourState={walks:Record<string /*memberId*/, {id:string; startedAt:number; budgetMin:number; mood:string; endpoint:{name,lat,lng}; walk:Walk; nudges:string[]; progress:{legIndex:number; at:number}; phoneLooks:number; endedAt:number|null; story:{title:string; line:string}|null}>};
// actions: 'start' {start:[lat,lng], endpointName, budgetMin, mood} → planWalk + llm.json('detour.nudges') → walks[memberId]
//          'advance' {legIndex} ; 'look' {} (phoneLooks++) ; 'end' {} → endedAt + llm.json('detour.story')
// detour.nudges prompt: "For each leg (turn, streets, POI name and kind, mood) write one sentence ≤ 9 words, lowercase, sensory when possible, never naming the final destination or giving distances. JSON {nudges:string[]}" ; mock: templates by turn+kind ("left where it smells like bread" for bakery, "straight until the trees stop" for park…).
// detour.story: JSON {title (≤ 8 words), line (≤ 20 words)}.
```
- [ ] **Step 1:** Test: `start` creates a walk with nudges.length === legs.length. Commit "feat(detour): reducer, prompts, mocks".
