# Cast Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Cast on the shared core: synchronized cast, locked-until-all reveal, catch mode with quorum, the pond, and a stage view with "why this cast" and the model ladder.

**Architecture:** Server state and reducer in `web/src/lib/apps/cast.ts` (registered in `apps/index.ts`), prompts in `web/src/lib/tasks/cast.ts`, mocks in `web/src/lib/mock/cast.*.ts`. Client route group `web/app/cast/*` built from the UI kit, driven by `useRoom('cast', code, member)` polling. Countdown uses `serverNow()` from the clock hook.

**Tech Stack:** as core. Extra: none (Web Audio + `navigator.vibrate` are built in). ICS download generated client-side.

**Spec:** `docs/superpowers/specs/2026-09-12-cast-design.md`. Visual contract: `docs/mockups/index.html` §Cast.

### Task 1: State and reducer

**Files:** `web/src/lib/apps/cast.ts`, `web/test/cast.reducer.test.ts`, register in `web/src/lib/apps/index.ts` (replace the stub entry only)

**Interfaces (produces):**
```ts
export type CastAnswer={text:string; at:number};
export type Cast={id:string; prompt:string; mode:'fishing'|'catch'; openedAt:number; deadlineAt:number; answers:Record<string,CastAnswer>; revealedAt:number|null; reasons:string[]; rejected:string[]};
export type Plan={id:string; castId:string; title:string; venue:string; subtitle:string; whenISO:string; pickerId:string; why:string; pulls:string[]; quorum:number; caughtAt:number|null};
export type CastState={name:string; mode:'fishing'|'catch'; casts:Cast[]; plans:Plan[]; scheduledAt:number|null; hostId:string|null};
// actions (memberId always present):
// 'setName' {name} ; 'castNow' {} (host or anyone in v1) → calls llm.json('cast.prompt') and pushes a Cast with deadlineAt=now+90_000
// 'schedule' {inMs} → scheduledAt=now+inMs (server does not have timers on Vercel: the reducer opens the cast lazily on the first action/poll after scheduledAt; implement `tick` action that the client sends every poll while scheduledAt is set and reached)
// 'answer' {castId,text} → sets answers[memberId]; when every current member has answered → revealedAt=now; if mode==='catch' and no open plan for this cast → llm.json('cast.plan') → push Plan{quorum: max(2, ceil(members*0.75)), pulls:[]}
// 'pull' {planId} → add memberId to pulls; when pulls.length>=quorum → caughtAt=now
// 'newPlan' {castId} → regenerate plan (adds previous venue to avoid list)
// 'setMode' {mode}
// 'tick' {} → opens scheduled cast if due
// initial(code): seeds name 'the basement' and the 14-day demo history from the mockup (5 casts with 4 authored answers each, one caught plan) marked {seeded:true} so the pond looks alive on first run.
```

### Task 3: Screens

**Files:** `web/app/cast/**`

- [x] **Step 1:** `useCastRoom()`: reads `?room=` (creates a room via POST /api/rooms when missing and rewrites the URL), uses `useMember`; if no name, renders an inline name sheet (TextField + CTA "Join the circle"). Exposes `{state, members, act, serverNow, me}`.
- [x] **Step 2:** Join (`/cast`): circle name, member avatars with names, pills "Cast now" and "Schedule in 2 min" (calls `schedule {inMs:120000}`), a QR of the current URL (UI `QR`), and the dock (home active). When a cast is open and unanswered by me → auto-navigate to `/cast/cast`.
- [x] **Step 3:** The cast lands (`/cast/cast`): `Ring` (SVG, stroke-dashoffset from `(deadlineAt-serverNow())/90000`), prompt H2, member status row (done/typing/idle; typing = member has `typingAt` within 5 s: send action `typing` throttled every 3 s while composing), CTA opens `Sheet` with `TextField multiline` and CTA "Cast it" → `answer`. On first render of a newly opened cast: `navigator.vibrate?.([120,60,120])` and a 400 ms two-tone via Web Audio (create AudioContext on the join CTA click so iOS allows it).
- [x] **Step 4:** Tonight (`/cast/tonight`): `AnswerCard` for each member: own answer visible; others `locked` (CSS `filter: blur(6px)` on text + lock chip) until `revealedAt`; on reveal animate blur→0 over 600 ms. Pill "N of M cast". When mode is catch and a plan exists → CTA "See the catch".
- [x] **Step 5:** Catch (`/cast/catch`): `PlanCard` (map thumb = static SVG grid with a pin, title, subtitle, date, picker chip), `QuorumBar` (fill = pulls/members, marker at quorum/members), avatar stack with pulled state, CTA "Pull the line" → `pull`; when caught: mint pill "Caught · invite sent", CTA "Add to calendar" (Blob ICS download: `BEGIN:VCALENDAR…DTSTART` from whenISO), ghost "Suggest a different night" → `newPlan`.
- [x] **Step 6:** Pond (`/cast/pond`): timeline of casts (newest first) with prompt, avatar stack of answerers, "N of M"; caught plans show the mint "caught" chip; tap → `/cast/tonight?cast=ID` (read-only reveal of that cast).
- [x] **Step 7:** `pnpm shots` for `/cast?room=TEST` after seeding a room via the API (script the seed in `scripts/seed-cast.ts` if useful) and for `/cast/tonight`, `/cast/catch`, `/cast/pond`; compare against `docs/mockups/index.html` §Cast; fix. Commit "feat(cast): screens".
