# Palate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Palate on the shared core: onboarding into a flavor profile, a ranked menu with reasons and hard allergen blocks, table mode that merges palates, the chef card in the menu's language, and a stage view of the merged flavor map.

**Architecture:** Deterministic scoring in `web/src/lib/palate/score.ts` over an authored ingredient table; three demo menus shipped parsed; pasted menus parsed by `palate.menu`. Server state per room (a table) in `web/src/lib/apps/palate.ts`; each member's palate lives in room state so the table merge is server-side. Client route group `web/app/palate/*`.

**Tech Stack:** as core. Extra: none (OCR is out of scope tonight).

**Spec:** `docs/superpowers/specs/2026-09-12-palate-design.md`. Visual contract: `docs/mockups/index.html` §Palate.

## Global Constraints

### Task 1: Data and scoring

**Files:** `ingredients.json`, three menus, `score.ts`, `test/palate.score.test.ts`

**Interfaces (produces):**
```ts
export type Axes={coconut:number; smoky:number; sour:number; herbal:number; sweet:number; fermented:number}; // 0..1
export type Palate={axes:Axes; families:{label:string; count:number}[]; never:string[]; loved:string[]};
export type Dish={id:string; name:string; price?:number; description?:string; ingredients:string[]; section?:string};
export type Scored={dish:Dish; score:number; status:'ok'|'unknown'|'never'; reason:string; hits:string[]; blockedBy?:string};
export function dishVector(d:Dish):{axes:Axes; known:number; allergens:string[]}; // ingredient lookup by name/alias, mean of axes
export function scoreDish(p:Palate, d:Dish):Scored; // cosine(p.axes, dish.axes)*70 + familyOverlap*30 → 0..100; status rules per constraints; reason = top 2 shared axes/ingredients as "coconut · galangal"
export function rankMenu(p:Palate, dishes:Dish[]):Scored[];
export function mergeTable(ps:Record<string,Palate>, dishes:Dish[]):{everyone:{dish:Dish; scores:Record<string,number>; min:number}[]; splits:{dish:Dish; scores:Record<string,number>; spread:number; lowest:string}[]; blocked:{dish:Dish; by:string; allergen:string}[]};
// everyone: min ≥ 75 sorted by min desc; splits: spread ≥ 40; blocked: any member's never
```
- [ ] **Step 1:** Author the ingredient table (Thai, diner, Portuguese coverage) and menus (Bangkok Balcony with the mockup's dishes: massaman, larb moo, khao soi, house special noodle with ingredients [], pad thai; plus ~10 more; Ritter's Diner; Tasca Lisboa in Portuguese with `language:'pt'`). Tests: massaman scores > 80 for a coconut-heavy palate; a sesame-containing dish is `never` for a sesame-never palate; house special is `unknown`; `mergeTable` puts massaman in `everyone` for three coconut palates and green curry in `splits` when one member scores it 24. Implement; pass. Commit "feat(palate): data and scoring".

### Task 2: State, reducer, prompts, mocks

**Files:** `src/lib/apps/palate.ts`, `src/lib/tasks/palate.ts`, `src/lib/mock/palate.*.ts`, `test/palate.reducer.test.ts`

**Interfaces (produces):**
```ts
export type PalState={palates:Record<string /*memberId*/,Palate>; menuId:string|null; pastedMenu:{restaurant:string; language:string; dishes:Dish[]}|null; known:Record<string /*dishId*/,{allergenCleared:string[]; at:number}>; order:{dishId:string; qty:number}[]};
// actions: 'profile' {loved:string[], never:string[]} → llm.json('palate.profile') → palates[memberId]
//          'pickMenu' {menuId} ; 'pasteMenu' {text} → llm.json('palate.menu') → pastedMenu
//          'clear' {dishId, allergen} → known[dishId] (dish becomes scorable if ingredients known, else stays unknown but "asked")
//          'buildOrder' {} → order from mergeTable.everyone (qty = ceil(members/2)) + splits as ×1
// prompts: palate.profile "Map loved dishes to six axes (0..1) and 3–4 flavor families with counts; JSON {axes, families}"; palate.menu "Parse menu text into dishes with ingredient guesses and confidence; keep the menu language in names; JSON {restaurant, language, dishes:[{name,price,ingredients,confidence,section}]}"; palate.reason (batched: input dishes+palate → JSON {reasons:{[dishId]:string ≤ 14 words}}); palate.chefCard "Write a polite allergen question for the kitchen in <language> plus English; JSON {native, english}".
// mocks: profile by keyword rules (coconut/curry→coconut, grill/char→smoky, lime/vinegar→sour, mint/basil→herbal, dessert→sweet, kimchi/miso→fermented); reasons templated from `Scored.hits`; chefCard has authored Thai and Portuguese strings for sesame/peanut/shellfish/dairy/gluten.
```
- [ ] **Step 1:** Tests: `profile` stores a palate; `pickMenu` + rank yields the expected order; `clear` makes the house special rank once ingredients exist. Commit "feat(palate): reducer, prompts, mocks".
